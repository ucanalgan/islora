# Islora 0.5.0-beta.3

- Choose **Sakin**, **Normal** or **Canlı** for the music wave on the Appearance page. The choice changes how fast and how far the bars move. **Normal** keeps the previous motion.
- The choice is saved as `wave_style` in `config.toml`; existing settings use **Normal**. Turning the wave off or enabling Windows Energy Saver still keeps the bars still.

This preview continues the volume and brightness flyout behavior from beta.2. Real-screen and end-to-end checks are planned before 0.5.0.
