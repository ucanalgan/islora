# Islora 0.6.0-beta.1

- Notifications from any app that posts to Windows Notification Center can appear in Islora after enabling **Windows bildirimlerini göster** in Settings and granting Windows access. Generic and other Windows notification layouts are read; when a layout has no readable text, the source app still appears. Notification text stays in memory and is never written to the settings file or logs.
- Click a preview to open its source app. For a WhatsApp Web notification from Chrome, Islora selects an existing WhatsApp tab when available. Windows does not expose the original notification's action to the listener, so this cannot open the exact conversation or message. Right click a preview to mute that app in Islora; Settings can clear the muted app list.
- **Odak oturumunda gizle** hides previews during a running Windows Focus session. Notifications already waiting to show are discarded when Focus starts.
- Music and a running timer keep their existing priority and companion bubble behavior. A new notification interrupts them briefly, then they return with their remaining time updated.
- Choose the island's display under **Düzen**. The selection is saved; if that display disconnects, Islora uses the primary display until it returns.
- Moved the settings window's layout and controls into the app layer, keeping shared geometry and platform-independent behavior in the core.
- The standalone exe checks Windows notifications every five seconds. Package identity would allow change events, but is not part of this beta's distribution.
- Fixed an empty translucent Windows level flyout appearing above the taskbar after Islora closes. The shell flyout is now matched by its small bottom-centre geometry, and Islora no longer minimises its content or reopens an expired empty host.

Automated tests and Clippy passed. The synthetic notification demo stayed running. A real notification from a messaging app, its app icon, click and mute behavior, the Windows access prompt, and Focus behavior still need a hands-on check before a stable release.
