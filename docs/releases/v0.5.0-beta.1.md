# Islora 0.5.0-beta.1

This preview reduces duplicate volume and brightness indicators on Windows 11.

- Islora hides the Windows level flyout while its own volume and brightness notices are enabled. The volume and brightness keys continue to change the system level normally.
- Volume and brightness can be turned off individually in Settings > Notices or with `notices_off` in `config.toml`. If either is off, the Windows flyout remains available.
- The release notes link in the tray opens the releases page for preview builds.

The Windows flyout behavior was checked with real keys on the development machine. Other Windows builds may use a different shell window.
