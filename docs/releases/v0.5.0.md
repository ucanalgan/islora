# Islora 0.5.0

- Islora hides the Windows volume and brightness flyout while its own notices for those levels are enabled. Either notice can be turned off separately; the Windows flyout remains available when one is off.
- The compact music wave now has **Sakin**, **Normal** and **Canlı** motion choices. Existing settings use **Normal**, which keeps the earlier motion.
- Turning **Ses dalgası** off removes the bars from the pill and gives their space back to the music title. Windows Energy Saver hides the wave too, then restores the saved choice when it ends. Hidden waves stop their compositor animations.
- Settings opens visibly again when Islora is started from a background process.

The automated unit tests, Clippy and release build passed. Mouse, keyboard and end-to-end interaction tests were deferred for this release at the user's request.
