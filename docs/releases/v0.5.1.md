# Islora 0.5.1

- Fixed Windows' volume and brightness flyout remaining hidden after Islora closes normally. Islora now restores the shell window and its content when it stops suppressing the flyout.
- Turning off either Islora level notice also restores the Windows flyout immediately.

The 0.5.0 mouse and keyboard interaction tests remain scheduled for later. Unit tests, Clippy and the release build passed for this fix.

If an older build already left the Windows flyout hidden, restarting Windows Explorer once restores that shell state.
